# KB-05: Old capstone policy

Document ID: KB-05
Version: v1
Effective date: 1 May 2026
Status: SUPERSEDED BY KB-02 v3

## Archive notice

This document is historical. It was superseded by KB-02 v3 on 1 Oct 2026. It is not valid for cases assessed on or after that date. Keep this notice attached to the text when indexing it so that a retrieved excerpt cannot be mistaken for current policy.

## Historical pass score

Under this old version, the capstone pass score was 60/100. This historical threshold is retained only to demonstrate version conflicts. It must not be used to pass a learner with a score below the current threshold of 70.

## Historical deadline time

The old version used a submission cutoff of 18:00 PKT. That time is superseded. For the October 2026 assessment, the current published deadline is 9 Oct 2026 at 17:00 PKT under KB-02 v3.

## Why the archive exists

Learners may have screenshots, copied messages, or older handouts. A coordinator should be able to explain why those materials differ from the current policy. Archiving the old text helps explain the disagreement; it does not make both versions equally applicable.

## How to use a retrieved archive excerpt

When an archive excerpt is retrieved for a current case, look up its status and the replacement document. Use the replacement for the decision. The answer may cite both documents to explain the change, but the current rule must control the result.

## Learner claims

A claim that a colleague passed with 60 in an earlier cohort does not authorize a current exception. Do not infer an exception from past practice. If a learner disputes the change, record the concern and refer it for human clarification without changing the current score threshold.

## Historical case limitation

If a question asks for a historical decision from before 1 Oct 2026, clearly state that this pack only preserves the old score and cutoff time. It does not provide a full historical program record or all former policies. Do not claim that the archive contains everything needed for a historical certificate decision.

## Assessment relevance

This document intentionally overlaps in wording with the current capstone policy. A system that retrieves by keywords alone may find both. The system must preserve version metadata and choose the applicable source rather than selecting whichever excerpt appears first.
